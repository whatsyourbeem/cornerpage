# 업종별 재사용 데이터 — boutique-fitness

빌더가 카피 생성·블록 채우기에 참고하는 이 vertical 전용 자산. **이 목록은 후보·예시일 뿐 강제 목록이 아니다.** 실제 그 스튜디오에 해당하는 사실만 사용하고, 사장님이 준 정보를 우선한다.

## 목차
1. 강점 후보 (어느 블록을 보강하는지 기준으로 정리)
2. 이용흐름(How It Works) 표준 골격
3. 예상 FAQ 질문 세트

**general과의 차이**: general의 "업종 2축 분류 참고표"(축A 톤·축B 레이아웃)는 여기 없다. `definition.md` 6장에서 확정했듯 이 vertical은 업체마다 분류하지 않고 블록 구성·순서·톤을 고정했기 때문이다.

## 1. 강점 후보 (블록별)

강점 체크리스트가 빈약할 때 각도를 넓히는 참고용. 실제 해당하는 것만 사용. `definition.md` 4장의 증거 위계(직접증거 > 간접증거 > 부가요소)에 맞춰, 어느 블록을 보강하는지 기준으로 정리했다 — general처럼 업종 전체를 뭉뚱그린 목록이 아니라, 강점 하나가 어느 블록으로 가야 하는지 바로 알 수 있게.

- **`professionals` 보강용** (간접증거): 보유 자격증 종류(생활스포츠지도사, NASM-CPT, NSCA-CPT, 물리치료사 면허 등), 임상·재활 경력, 특정 체형·질환 전문(허리디스크, 거북목, 산후 회복 등), 대회 입상 이력, 지도 스타일(체계적 프로그램 설계, 꼼꼼한 자세 교정)
- **`trust_strip` 보강용** (간접증거): 누적 회원 수, 재등록률, 운영 연차, 회원-트레이너 매칭 성공 사례 수
- **`facility` 보강용** (부가요소): 특정 브랜드 기구(리포머·타워 등 브랜드명이 신뢰 요소일 수 있음), 프라이빗룸 여부, 위생·청결 관리 방식
- **`atmosphere` 보강용** (부가요소): 1:1이라 다른 회원 눈치 안 봐도 되는 조용함, 채광, 음악, 청결도 — 특히 "초보자 눈치 안 봐도 됨"은 `definition.md` 5번 불안과 직결되니 있으면 적극 활용
- **`menu` 보강용**: 맞춤 프로그램 설계(체형·목표별 커스텀), 소수정예 인원 제한, 초보자 전용 코스 별도 운영

**주의**: `transformations`·`reviews`(직접증거)는 여기 "각도를 넓히는" 방식으로 보강할 수 없다 — 사장님이 준 실제 사례·후기가 없으면 이 두 블록은 그냥 `null`이다. 강점 후보로 대체하면 사실 조작이 된다(`../../for-context/boutique-fitness/blocks.md` 블록 3 참고).

## 2. 이용흐름(How It Works) 표준 골격

`../../for-context/boutique-fitness/blocks.md` 블록 8에서 이미 확정한 내용의 요약. 초안은 아래 골격으로 생성 후, 사장님이 STEP6에서 준 특이사항만 반영해 검수.

- **체험 프로그램 있음**: ① 상담 신청(카톡/DM/전화) → ② 체험 수업 → ③ 등록
- **체험 프로그램 없음**: ① 상담 신청 → ② 등록
- **상담 단계를 생략한 골격은 만들지 않는다** — 이 vertical의 신뢰 구조상 필수(`definition.md` 6번 반례 참고).

## 3. 예상 FAQ 질문 세트

사장님에게 제시할 질문 후보. 답한 것만 FAQ 블록에 포함. 이미 페이지에 있는 정보(`facility`의 샤워실·주차 등)와 모순되지 않게 주의.

- **초보자 불안 관련** (`definition.md` 5번, 우선순위 최상위): 운동 경험이 없는데 괜찮을까요? / 몸이 안 좋은데도 가능한가요? / 나이 제한이 있나요?
- **강매 불안 관련** (사장님이 실제로 확인해준 정책이 있을 때만): 상담받으면 무조건 등록해야 하나요? / 상담 비용이 있나요?
- **운영 실무**: 환불 규정은 어떻게 되나요? / 준비물이 필요한가요(운동복·실내화·수건 등)? / 체험 수업이 있나요?
- **시설 관련** (`facility` 데이터와 반드시 일치): 샤워실·라커 있나요? / 주차 가능한가요?
- **팀 스튜디오인 경우만**: 트레이너를 지정해서 받을 수 있나요?
