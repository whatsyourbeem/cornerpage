# 00. 정의 — 부티크 피트니스에서 "좋은 홈페이지"란 무엇인가

> Step 1 결과물. 이 vertical의 모든 블록 구성·순서·질문 설계(01~05)는 이 문서의 판단을 근거로 삼는다.

## 1. 업종 범위

**PT·필라테스·요가 등 1:1 또는 소수정예 트레이너 주도형 스튜디오("부티크 피트니스")**만을 다룬다.

**명시적으로 제외**: 대형 회원제 헬스장(저관여·근접성 중심). 신뢰의 대상이 "시설/운영"이지 "특정 개인"이 아니라서, 여기서 다루는 논리(신뢰의 단위=사람)가 성립하지 않는다. 대형 헬스장은 필요해지면 별도 vertical(`gym-membership` 등)로 다룬다. 당분간은 `general`로 처리한다.

## 2. 이 업종의 특성

1. **유입 경로가 대체로 "웜(warm) 트래픽"이다.** 인스타그램에서 트레이너 콘텐츠를 몇 번 보고 관심이 생겼거나, 지인 추천을 받고 확인하러 들어오는 경우가 많다. 이 페이지의 역할은 "존재를 알리는 것"이 아니라 **"이미 생긴 관심을 신뢰로 전환시키는 것"**이다.
2. **신뢰의 단위가 "공간"이 아니라 "사람"이다.** 몇 주~몇 달을 그 트레이너와 붙어서 운동해야 하니, "이 트레이너가 내 몸을 맡길 만한 사람인가"가 핵심 질문이다.
3. **업계 특유의 "부정적 사전 인식"이 있다.** "상담 갔다가 고압적으로 비싼 패키지를 강매당했다"는 후기가 흔해, 방문자는 은연중에 방어적이다. 첫 CTA가 부담스러우면 바로 이탈한다.
4. **"나도 할 수 있을까"라는 자격지심이 큰 진입장벽이다.** 특히 초심자는 "몸이 안 좋은데도 괜찮을지", "운동 잘하는 사람들만 가는 곳 아닌지" 불안해한다.
5. **가격은 대부분 상담 후 결정된다.** 맞춤 프로그램이라 고정가를 못 박기 어렵고, 고정가를 크게 걸면 오히려 "이 가격에 나도 되나" 하는 비교·이탈이 생긴다.
6. **비싼 비용을 정당화해야 한다.** 대형 헬스장 대비 훨씬 비싼 1:1/소수정예 비용을 내는 것이므로, "친절하다"·"자격이 있어 보인다" 같은 간접 인상만으로는 구매가 정당화되지 않는다. **직접적 성과 증거**가 필수다.

## 3. 정의

> **방문자가 이미 가진 막연한 관심을, "이 스튜디오라면 실제로 나를 변화시켜 줄 수 있겠다"는 확신으로 바꿔서, 부담 없는 상담 신청까지 이끄는 페이지.**

신뢰의 대상은 궁극적으로 "사람"(트레이너)이 맞지만, 그 신뢰를 얻는 순서는 **"이 사람이 어떤 사람인지"보다 "이 사람이 실제로 만든 결과가 무엇인지"가 먼저**다 (아래 4장 참고).

## 4. 신뢰 근거의 위계 — 직접 증거 우선

처음엔 이 업종의 신뢰 근거를 "성과·데이터형 / 친근·관계형 / 임상·자격형"이라는 톤의 종류로 나눌 수 있다고 가정했으나, 실제 사례 검토와 논의 결과 **이런 자연스러운 유형 분화는 없었다**. 대신 신뢰 근거는 종류가 아니라 **직접성의 정도**로 위계가 갈린다.

- **직접 증거** (최우선, 사실상 필수):
  - `transformations`(비포/애프터) — "이런 결과가 가능하다"는 시각적 증거. 단, 사장님이 직접 고른 사진이라 선별 편향 의심 가능.
  - `reviews`(리뷰) — 제3자의 목소리라 위 의심을 우회하는 독립적 증거.
- **간접 증거** (보조):
  - `professionals`(전문가 프로필: 자격증·경력) — "유능해 보인다"는 인상은 주지만 "나를 변화시킨 적이 있다"는 증명은 못 한다. 직접 증거를 만든 사람이 누구인지 공개하는 역할.
- **부가 요소** (증거 확보 후에나 의미 있음):
  - 친근함·톤·분위기 — 상담받을 때 편안한 사람이면 더 좋다는 정도. 이것만으로 구매를 정당화하지 않는다.

**이 위계가 블록 순서를 결정하는 근거다** (상세 순서와 근거는 `blocks.md` 참고). 전문성(professionals) → 성과(transformations) → 사회적 검증(reviews) 각 단계가 앞 단계의 "그런데 정말이야?"라는 의심을 순서대로 지우는 구조 — 라는 처음 가설은, 실제로는 **결과(transformations·reviews)를 먼저 보여주고 그걸 만든 사람(professionals)을 나중에 공개하는 순서가 더 설득력 있다**는 결론으로 정정되었다.

## 5. 방문자 불안 해소 순서

| 순서 | 방문자의 속마음 | 페이지가 해줘야 할 일 | 직접성 |
|---|---|---|---|
| 1 | "여기 뭐 하는 곳이지?" | 3초 안에 업종·지역·핵심 정체성 인지 | - |
| 2 | "진짜 효과가 있나?" | 회원 변화 사례(비포/애프터) | 직접 |
| 3 | "정말이야? 다른 사람도 그렇게 느꼈나?" | 실제 후기(원문 그대로) | 직접 |
| 4 | "이걸 만든 사람은 누구지?" | 자격·경력·전문분야 공개 | 간접 |
| 5 | "나도 할 수 있는 수준일까?" | 초보자 배려 여부, 지도 스타일 (미해결 — `blocks.md`에서 배치 결정 필요) | - |
| 6 | "상담 가면 강매당하지 않을까?" | 저부담 CTA 문구·톤, 이용방법에 상담→체험→등록 흐름 명시 | - |
| 7 | "가격·위치는?" | 상담 유도(가격은 여기서 확정 X), 접근성은 보조 정보 | - |

## 6. general과의 구조적 차이

- **축A(톤 분류)·축B(레이아웃 분류) 모두 미적용.** general은 카페부터 장례용품까지 완전히 다른 업종을 하나의 스키마로 통일하기 위해 업체마다 분류가 필요했지만, boutique-fitness는 처음부터 이 vertical 하나의 논리로 블록 구성·순서를 확정했으므로 분류 메커니즘 자체가 불필요하다.
- **대신 `lead_emphasis`(사장님 자기보고) 필드로 개인화한다.** "가장 자신 있게 내세우고 싶은 게 뭔가요?"(`transformations`/`reviews`/`professionals`/`facility` 중 택1)를 사장님에게 직접 물어, 선택된 블록만 증거 클러스터 맨 앞으로 끌어올린다. 이는 LLM의 추측이 아니라 사장님의 자기보고이므로 `copywriting.md`의 "없는 걸 지어내지 않는다" 원칙과 부합한다. 상세 로직은 `blocks.md`에서 다룬다.

## 7. 반례 (나쁜 정의)

- 대형 헬스장처럼 "가격표부터 크게 보여주고 즉시 등록 유도"하는 페이지 — 신뢰가 안 쌓인 상태의 조기 CTA라 역효과.
- 트레이너 얼굴·서사 없이 시설 사진만 나열한 페이지 — 신뢰 단위가 "사람"인데 "공간"만 보여주는 셈.
- 자격증·경력만 나열하고 실제 변화 사례·후기가 없는 페이지 — 간접 증거만 있고 직접 증거가 없어 "비싼 값을 할까"라는 핵심 의심이 안 풀림.
