## 2. 업종별 기본 강점 후보

강점 체크리스트가 빈약할 때 각도를 넓히는 참고용. 실제 해당하는 것만 사용.

- **카페·식당**: 직접 로스팅/제조, 오래된 운영 연차, 시그니처 메뉴, 좌석·공간 분위기, 예약 가능, 반려동물 동반, 주차
- **미용실·네일**: 동시 시술 인원, 역세권 접근성, 이달의 아트, 원장 경력, 프라이빗룸, 예약제 운영
- **헬스장**: 규모(평수), 트레이너 경력, 1:1 전문, 편의시설(샤워실·주차), 24시간, 접근성
- **병의원·치과**: 전문의 자격, 임상경력 연차, 대학병원 이력, 협진 체계, 최신 장비, 야간진료, 주차
- **학원**: 강사 경력, 소수정예, 커리큘럼 체계, 합격·성과 실적(과장 금지), 접근성
- **장례용품·긴급업종**: 운영 연차, 24시간 대응, 직접 제작·공급, 빠른 준비, 종교별 구비
- **스터디카페**: 24시간 무인, 좌석 구분(포커스/카페존), 프라이빗룸, 사물함·대여, 접근성

## 3. 업종별 이용흐름 템플릿

업종·CTA 방식으로 초안 생성 후 검수. 특이 절차만 추가.

- **예약형(네일·미용·헬스)**: ① 예약(DM/전화/네이버) → ② 방문 → ③ 시술/상담
- **상담형(장례·법률·인테리어)**: ① 전화 상담 → ② 상황에 맞는 안내 → ③ 준비·진행
- **진료형(병의원)**: ① 예약 → ② 방문 접수 → ③ 진료
- **무인형(스터디카페)**: ① 키오스크 선택 → ② 결제 후 즉시 이용 (2단계)
- **학원형**: ① 상담 신청 → ② 방문 상담·레벨테스트 → ③ 수강 시작

## 4. 업종별 예상 FAQ 질문 세트

사장님에게 제시할 질문 후보. 답한 것만 FAQ 블록에 포함. 이미 페이지에 있는 정보(영업시간·위치)는 원칙적으로 제외하되, 사장님이 특별히 강조하려는 경우는 허용.

- **카페·식당**: 주차 되나요? / 예약 되나요? / 반려동물 동반 가능한가요? / 단체 가능한가요? / 포장 되나요? / 콘센트·와이파이 있나요?
- **네일·미용**: 예약 필수인가요? / 시술 시간 얼마나 걸리나요? / 제거만도 가능한가요? / 주차 되나요? / 아이 동반 가능한가요?
- **헬스장**: 회원권 종류가 어떻게 되나요? / 환불 규정은요? / 주차 되나요? / 샤워실 있나요? / PT 상담은 어떻게 하나요?
- **병의원·치과**: 주차 되나요? / 실손보험 적용되나요? / 당일 진료 가능한가요? / 어린이 진료도 하나요? / 야간진료 하나요?
- **장례용품**: 비용은 어떻게 되나요? / 급하게 당일 준비 가능한가요? / 종교별 용품도 있나요? / 상담만 받아도 되나요?
- **학원·공방**: 체험 수업 있나요? / 수강료는 어떻게 되나요? / 재료비 별도인가요? / 초보도 가능한가요?
- **스터디카페**: 회원가입 어떻게 하나요? / 24시간 언제나 들어갈 수 있나요? / 환불 가능한가요? / 대여 물품 있나요? / 위치가 어디인가요?
